# Examples

The canonical DB-X example is [`examples/postgres`](https://github.com/rtorcato/db-x/tree/main/examples/postgres)
in the repo — a runnable project that applies a `todos` schema to Postgres with
the standalone `db-x` CLI.

:::warning Experimental
DB-X is an early prototype. Do not point it at a database you care about.
:::

## `examples/postgres` — standalone DB-X

The schema (a `todos` table) is imported from `@db-x/postgres-library` and
connected via `<DatabaseTarget url={...}>`, so `db-x` runs it against any
Postgres — no Infra-X involved:

| File | Runtime parent | CLI | Use case |
| --- | --- | --- | --- |
| [`dbx.tsx`](https://github.com/rtorcato/db-x/tree/main/examples/postgres/dbx.tsx) | `<DatabaseTarget url={...}>` | `db-x` | Points at any Postgres via a `postgres://` URL — a local container or a managed DB. |

The bundled [`docker-compose.yml`](https://github.com/rtorcato/db-x/tree/main/examples/postgres/docker-compose.yml)
provides a throwaway Postgres to apply against; or set `DATABASE_URL` to an
existing one.

Follow the [Quickstart (Docker)](./getting-started/quickstart-docker.mdx) to run
it against a local Postgres, then read [Time Machine](./concepts/time-machine.mdx)
for snapshots and rollback (on the roadmap).
