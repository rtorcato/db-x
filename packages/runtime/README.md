The DB-X runtime: JSX runtime functions, the `defineComponent` contract, the reconciler that turns JSX into a resource graph, the diff engine, and the state I/O layer.

This package is a peer dependency of every third-party DB-X component library.

See [`docs/architecture.md`](../../docs/architecture.md) and [`docs/component-api.md`](../../docs/component-api.md).
